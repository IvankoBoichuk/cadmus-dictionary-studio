# ADR-0001: Модульний моноліт із фоновим worker

- Статус: Accepted
- Дата: 2026-08-13
- Jira: BH-175

## Контекст

OCR, preprocessing та ML є довгими й ресурсоємними операціями. Виконання в HTTP-запиті спричиняє таймаути, але повна мікросервісна архітектура створює непропорційну складність для greenfield магістерського MVP.

## Рішення

Використати модульний моноліт для API та предметної логіки. Довгі use cases запускати окремим worker-процесом через Redis. API і worker використовують один backend source tree та предметну модель.

## Наслідки

- прості транзакції й локальне налагодження;
- важкі задачі не блокують HTTP;
- модульні межі мають контролюватися тестами та review;
- worker можна масштабувати незалежно;
- виділення сервісів відкладається до появи виміряної потреби.

## Відхилені альтернативи

- синхронний моноліт: неприйнятний для довгих jobs;
- мікросервіси: надмірні deployment та observability витрати для MVP.
