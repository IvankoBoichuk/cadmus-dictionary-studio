# ADR-0002: PostgreSQL і S3-сумісне object storage

- Статус: Accepted
- Дата: 2026-08-13
- Jira: BH-175

## Контекст

Cadmus має транзакційні зв'язки між проєктами, сторінками, запусками, записами, версіями та правками. Водночас OCR-вивід і специфічні поля словників є варіативними, а PDF та зображення — великими бінарними об'єктами.

## Рішення

PostgreSQL є системою запису для метаданих і предметних сутностей; JSONB використовується для варіативних payload. PDF, зображення та pipeline artifacts зберігаються в S3-сумісному сховищі, локально — MinIO. База містить URI, checksum, MIME, розмір і provenance.

## Наслідки

- транзакційна цілісність та звичайні міграції;
- гнучкість без окремої document database;
- життєвий цикл DB-запису й object необхідно узгоджувати;
- backup policy має охоплювати обидва сховища.

## Відхилені альтернативи

- MongoDB як основна БД: слабше виражає критичні зв'язки та ревізії;
- BLOB у PostgreSQL: ускладнює роботу з великими файлами й резервування.
