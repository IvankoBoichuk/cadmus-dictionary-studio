# ADR-0004: Provenance-first і незмінний source layer

- Статус: Accepted
- Дата: 2026-08-13
- Jira: BH-175

## Контекст

Для наукової ретроцифровізації недостатньо зберігати фінальний виправлений текст. Потрібно відрізняти спостереження OCR, автоматичну інтерпретацію, нормалізацію та ручне виправлення.

## Рішення

Кожне структуроване поле посилається на джерело, сторінку, геометрію/token IDs і processing run. `source_text` не перезаписується нормалізацією. Автоматичний результат є proposal, а ручні зміни зберігаються як revisions/annotations із автором і часом.

## Наслідки

- результат можна перевірити та відтворити;
- UI може синхронізувати поле з фрагментом скану;
- модель даних і запити стають складнішими;
- експорт повинен явно вибирати потрібну перевірену revision.

## Відхилені альтернативи

- одне mutable text field: втрачає першоджерело та історію;
- зберігати лише фінальний JSON: не дозволяє наукову перевірку.
